# Resume Placement Guide

## Best section
Place this under **Projects** near the top half of the resume, especially if you are targeting analyst roles.

## Best order
1. Strongest independent or portfolio project
2. Relevant coursework or technical projects
3. Supporting project work

## Best date format
Use a clean date like:
**Medicare Payment Intelligence Dashboard | 2026**

## Best tool tag line
**MySQL, Power BI, SQL, Data Cleaning, Dashboarding, Healthcare Analytics**
