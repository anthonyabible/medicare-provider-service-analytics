# Project Limitations and Next Steps

## Current limitations
- The dataset is a public-use file, so it is aggregated and does not include patient-level detail.
- Results depend on the public reporting rules and suppression rules used by CMS.
- Payment figures can be influenced by procedure mix, geography, and place of service, so they should not be treated as direct measures of provider quality.
- Without the final imported CSV outputs, the README findings section remains template-based until the queries are run.

## Strong next steps
- Add year-over-year comparison by loading multiple CMS annual files.
- Add a provider-type drillthrough page in Power BI.
- Add state-level small multiples or percentile benchmarking.
- Add a data-refresh note or parameterized import workflow.
- Add a short video walkthrough to the GitHub repo for extra portfolio polish.
