# Application Blurbs

## Data Analyst version
Built a MySQL + Power BI healthcare analytics project using CMS Medicare data to clean, model, and benchmark provider-service payment patterns through dashboard-ready reporting views.

## BI Analyst version
Developed a MySQL + Power BI portfolio project using official CMS provider-service data, creating a raw-to-clean SQL workflow, reporting views, and a one-page dashboard focused on payment drivers and state benchmarking.

## Reporting Analyst version
Created a reproducible MySQL + Power BI reporting project using CMS Medicare data to analyze provider specialties, procedure mix, place-of-service differences, and Connecticut vs. national performance.

## Healthcare Analytics version
Built a healthcare analytics project using CMS Medicare provider-service data to compare specialty-level payment volume, standardized payment patterns, and local-state benchmarking through SQL and Power BI.
