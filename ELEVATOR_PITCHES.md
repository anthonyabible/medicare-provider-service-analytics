# Elevator Pitches

## 15-second version
I built a MySQL + Power BI healthcare analytics project using official CMS Medicare data to analyze payment drivers, procedure mix, and Connecticut vs. national benchmarks.

## 30-second version
I used the CMS Medicare provider-service dataset to build a project in MySQL and Power BI that starts with raw data staging, moves into cleaning and weighted benchmarking, and ends with dashboard-ready views for analyzing provider specialties, HCPCS procedures, and Connecticut comparisons.

## 60-second interview version
I wanted a project that looked more like real analyst work than a classroom exercise, so I used the CMS Medicare provider-service dataset and built a workflow in MySQL and Power BI. I separated raw import from cleaned analytical modeling, used weighted payment and standardized-payment metrics, and then created reporting views for provider types, procedures, place of service, and state-level comparisons. I also added a Connecticut spotlight because it makes the project easier to discuss in interviews and shows that I can frame data in a way that is relevant to a local employer.
