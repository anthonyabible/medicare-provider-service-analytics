# Project Screenshot Checklist

Your final dashboard screenshot should show:
- 4 to 5 KPI cards at the top
- one ranked state visual
- one top provider-type visual
- one top HCPCS visual
- one Connecticut-specific visual
- no empty canvas space that looks accidental
- readable titles
- numbers formatted consistently

Bad screenshot signs:
- tiny unreadable text
- too many colors
- more than one page
- messy legends
- 20 slicers fighting for attention like unruly children
