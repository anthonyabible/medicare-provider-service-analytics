# Portfolio Project Card

## Project title
Medicare Payment Intelligence Dashboard

## One-line summary
A MySQL + Power BI portfolio project built on official CMS Medicare provider-service data to analyze payment drivers, procedure mix, site-of-service differences, and Connecticut benchmarking.

## Best quick pitch
I took a large public CMS healthcare dataset, built a clean SQL pipeline from raw import to reporting views, and prepared a Power BI dashboard that highlights provider-type, HCPCS, and state-level payment patterns with weighted metrics.

## Best audience for this project
- recruiters screening analyst candidates
- hiring managers for reporting, BI, or healthcare analytics roles
- teams looking for SQL + Power BI + business communication skills
