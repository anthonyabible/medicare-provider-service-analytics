# START HERE

## Fastest path to a finished portfolio project

1. Run `sql/01_setup_mysql.sql`
2. Run `sql/01b_load_data_template.sql` if you want to load the file with SQL, or use MySQL Workbench import
3. Confirm the import row count in `provider_service_raw`
4. Run `sql/02_clean_and_validate.sql`
5. Run `sql/03_analysis_queries.sql`
6. Run `sql/04_dashboard_views.sql`
7. Run `sql/05_readme_key_findings.sql`
8. Run `sql/06_data_quality_audit.sql`
9. Optional but recommended: run `sql/07_portfolio_export_views.sql`
10. Run `sql/08_exec_summary_output.sql`
11. Paste the output into `docs/README_FINDINGS_TEMPLATE.md`
12. Build one Power BI page using `assets/dashboard_mockup.png`
13. Save a screenshot as `assets/dashboard_screenshot.png`
