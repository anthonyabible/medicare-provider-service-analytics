# Hiring Manager Scan

## What this repo signals in under 30 seconds

- Real public dataset, not a toy file
- Clear SQL workflow from raw import to reporting layer
- Weighted logic instead of naive averages
- Business framing, not just technical screenshots
- Enough documentation that the project feels publishable and interview-ready

## What makes it credible

- Uses a public CMS dataset with provider, HCPCS, and place-of-service granularity
- Builds a typed analytical table rather than reporting directly from raw text columns
- Separates validation, analysis, dashboard views, and recruiter-facing documentation
- Includes a data quality audit so the work looks controlled rather than improvised

## What I would expect from a candidate who built this

Someone who can clean messy data, design practical metrics, explain tradeoffs, and communicate findings to a business audience.
